# 4.2.1 Levantamento de Requisitos

## Como os Requisitos Foram Levantados

A principal técnica utilizada foi com a entrevista com o cliente e observação. Com a entrevista conversei com a Manu que apresentou o ponto de vista de quem joga um sistema de RPG e a insatisfação de ter que carregar muitas fichas soltas e não poder consultar tais fichas e o Mestre Stalin (apelido dela) que mestra uma mesa de RPG e ela trouxe o ponto de sempre confundir o que ele como mestre pode ver as informações da ficha de seus jogadores. E vendo uma partida, pude perceber que os principais pontos que o sistema precisa é de organizar as informações da ficha além de uma forma de rolagens de dados atrelado ao jogador, já que eles se perdem muito no histórico de rolagens 

## Da Fala à Necessidade

|Número|Fala|O que é| necessidade por trás|
|---|---|---|---|
|F01|"Eu queria muito poder escreve a ficha do meu personagem ..." (Manu)|necessidade |O jogador precisa ter a capacidade de criar uma ficha no sistema para utilizar no meio de uma sessão de RPG|
|F02|"... que fosse simples de modificar" (Manu)| necessidade | O jogador precisa ter a capacidade de modificar a ficha que ele acabou de criar|
|F03|" sempre me esqueço do que está escrito na ficha dos meus jogadores..." (Stalin)| necessidade implícita | O mestre precisa ver dados da ficha dos jogadores|
|F04| "Os jogadores precisam definir quais dados o Mestre pode ver" (eu/Renan)| necessidade| O mestre não pode ver todos os dados, apenas os necessários|
|F05|"... além de sempre confundir na rolagem de dados" (Stalin)| necessidade implícita | O Sistema deve organizar a rolagens de dados dos jogadores e do mestre|
|F06|"O sistema tem que ser um servidor para que as alterações sejam visíveis a todos simultaneamente" (Renan/eu)| solução | Assim todos na mesa vão poder ver as fichas dos outros (só o que a pessoa deixou visivel).|

## Histórias de Usuário 
|Número| Histórias | Origem |
|---|---|---|
|HU01|Como ***Usuário***, quero ***Criar uma ficha na mesa que estou jogando*** para ***organizar as informaçoes do meu personagem***|F01|
|H02|Como ***Usuário **, quero ***Alterar dados da ficha que eu criei*** para ***mudar as informações da ficha ao decorrer da sessão***|F02|
|H03|Como ***Mestre***, quero ***ver a ficha dos jogadores*** para ***facilitar a organização das informações***|F03|
|H04|Como ***jogador***, quero ***alterar quais informações o mestre pode ver*** para ***manter sigilo de informações delicadas ou insignificantes ao mestre***|F04|
|H05|Como ***Usuário ***, quero ***rolar dados*** para ***ações no jogo como um geral***|F05|
|H06|Como ***Usuário***, quero ***ver o histórico de alterações e rolagens de dados*** para ***manter o jogo organizado*** |F05 / F02|
|H07|Como ***Usuário*** quero ***saber das ações dos outros jogadores*** para ***saber o que está acontecendo no jogo***|F06|

## Requisitos Funcionais
|Número|Nome|Requisito|origem|
|---|---|---|---|
|RF01|***Cadastrar Ficha***|O sistema deve permitir ao Usuário criar uma ficha na mesa|HU01|
|RF02|***Alterar Ficha***|O sistema deve permitir o Usuário alterar os dados da ficha|HU02 / HU04|
|RF03|***Visualizar Ficha***|O sistema deve permitir que outros usuários vejam os dados públicos da ficha|HU03|
|RF04|***Rolar Dados***|O Sistema deve permitir que haja rolagens de dados |HU05|
|RF05|***Ver histórico***|O sistema deve permitir aos usuários ver o histórico de ações feitas|HU06|

## Requisitos Não funcionais 
|Número|Categoria|Requisito|Origem|
|---|---|---|---|
|RNF01|***Acesso***|permitir a todos que estão usando o sistema veja as alterações e ações dos outros jogadores na hora que elas são feitas|HU07|
|RNF02|***Desempenho***|O sistema deve responder dentro de 3 segundos|4.1|
|RNF03|***Dispositivo***|O Sistema deve funcionar simultaneamente em diversos dispositivos pela web|HU07|
